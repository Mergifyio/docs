The Mitigation page lists the tests currently in quarantine, and could only be narrowed by test name — so a team wanting to release the tests that have since recovered had to read the Health column row by row.

A Health filter now narrows the list to the tests whose health is healthy, flaky or broken. The filtering happens on the server, so the count follows the filter and pagination walks the filtered set; a quarantined test that has stopped running entirely counts as healthy, since that is exactly the debt a team is trying to clear. Combined with the bulk action on the same page, releasing every recovered test is: filter on healthy, select all, remove.
